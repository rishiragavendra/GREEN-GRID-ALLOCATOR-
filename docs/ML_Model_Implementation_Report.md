## Approach

Traditional machine learning only. No deep-learning frameworks (TensorFlow/PyTorch) and no CNN, RNN, LSTM, GRU or transformer models are used. **SIFT is not used and is not applicable**: it is an image keypoint descriptor, while this project's inputs are numeric tabular time series. The actual feature extraction is: weather variables, cyclical time encodings, lag values (24 h, 168 h) and rolling statistics (24 h, 168 h).

## Not applicable

| Method | Why |
|---|---|
| BERT | Text/NLP transformer - the inputs are numeric tabular time series, not tokenised language. |
| CNN | Convolutional image model - there are no images or spatial grids in this dataset. |
| RNN / LSTM / GRU | Deep sequence models excluded by project scope; only traditional ML is used here. |
| SIFT | Image keypoint descriptor - meaningless for numeric weather/power readings. |
